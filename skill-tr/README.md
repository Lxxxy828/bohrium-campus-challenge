# 文献翻译 Skill（阅读03｜文献翻译）

把真实科研文献翻译成**段落级双语对照**结果：术语全篇一致、段落不漏不重、指代/否定/数字单位/公式/引用准确、每段可回原文核验。

## 用途与适用条件

- **用途**：科研论文（PDF/扫描件/多栏排版）的术语一致、段落对齐、可回溯的双语翻译。
- **适用**：需要术语表强制约束、段号对齐、引用与公式可回溯的科研翻译任务。
- **不适用**：文学/新闻等非科研文本的自由改写。

## 依赖与安装

- **无脚本、无第三方依赖**：本 Skill 是纯指令型工作流，不安装任何包。
- 运行时读取 PDF 使用平台提供的 `pdf-text-tool` / `pdf-render-tool` / `ocr-tool`。

## 输入与输出

**输入**
- `/input/case.json`（任务说明 + 材料路径 + 翻译范围/语言方向/覆盖要素）与 `task.md`。
- 实际论文 PDF/材料是唯一事实依据。

**输出**（写入 `/app/output/result.json`）
- `译文结果`：段落级双语对照 `paragraphs[]`（para_id / 原文 / 译文 / 原文定位 / 译法依据）。
- `术语表`：源术语 → 锁定译名的硬约束表。
- `evidence` / `uncertainties` / `notes`（术语一致率、段覆盖、变更日志等）。

## 调用示例（示意，非正式案例）

输入：一篇英文论文 PDF + "全篇译成简体中文，术语一致，段号对齐"。

示意输出（非正式案例）：

```json
{
  "case_id": "example",
  "status": "success",
  "术语表": {"entries": [{"term_id": "T01", "source_term": "diffusion", "translation": "扩散", "first_occurrence": "P2/第1页"}]},
  "译文结果": {"paragraphs": [{"para_id": "P1", "原文": "…", "译文": "…", "src_loc": {"page": 1}}]},
  "notes": {"term_consistency": {"checked": 42, "inconsistent": 0, "rate": "100%"}}
}
```

## 自查方法（提交前逐项检查）

1. **术语稳**：术语表是否硬约束执行；术语一致率是否已计算，不一致项是否列入 `uncertainties`。
2. **段落全**：`para_id` 与原文一一对应，无漏段/重段/错位；跨页跨栏截断段是否合并后单号。
3. **关系准**：数字/单位/公式/引用编号/否定/限定/因果让步逐项 diff 是否通过。
4. **可核验**：每段译文是否有原文定位（页码/段号/栏位）与译法依据。
5. **诚实性**：读不出/OCR 不确定/指代未明/材料冲突是否显式标注，未补造。
6. **状态如实**：有未决项则 `status=partial`，不要为了好看写 `success`。

## 失败处理

| 异常 | 处置 |
|---|---|
| 无文字层/扫描件 | 走 OCR，全部标 `[OCR]` 与置信度，status 至少 partial |
| 公式/表格为图片 | 保留位置说明 + OCR 内容，标"待人工确认" |
| 参考文献无法解析 | 逐条保留原文，标"未译（引用标记保留）" |
| 原文残缺/页码缺失 | 只译能读到的部分，缺失处记入 `uncertainties` |
| 超长文/预算不足 | 分批，先写 partial 保底再改进；未译区间写清起止 |
| 工具读取失败 | 重试一次；仍失败则 status=partial/failed，不编造 |

预算铁律：**先落盘再润色**——第 1 版至少含切分清单 + 术语表草稿 + 前几段双语对照并写入 result.json（status=partial）。

## 限制与维护

- 术语译名以可核查来源为准；无把握时保留原文 + 临时译名并标注，不臆造权威译名。
- 维护：更新 SKILL.md 工作流时同步本 README；术语表模板格式与 SKILL.md §4 保持一致。
